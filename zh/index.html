常见问题

      

        我的健康数据真的完全不会离开我的电脑吗？
        
是的。本站部署在静态托管上，没有任何后端接口或分析脚本，所有文件读取与计算均在浏览器本地 Web Worker 中完成。你可以在浏览器开发者工具的 Network 面板中确认 0 字节外发。

      

      

        支持解析哪些 Apple 健康指标？
        
涵盖 15 项核心日常指标——静息心率、HRV（SDNN）、步行心率、睡眠（总时长、深睡、REM）、步数、活动能量、锻炼时长、血氧、呼吸频率、最大摄氧量（VO₂max）、收缩压/舒张压与体重，以及 35 种官方体能训练类型。

      

      

        这些结果能当作医疗诊断吗？
        
不能。本工具仅负责把你的苹果健康记录整理成清晰格式，供个人回顾或配合 AI、电子表格分析趋势。任何健康与医疗决策请务必咨询专业医生。
